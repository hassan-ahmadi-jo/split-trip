{% trans 'About SplitTrip' %}

{% trans 'SplitTrip is a simple web app designed to make tracking and sharing travel expenses easier for groups.' %}

{% trans 'It helps friends organize trips, record shared costs, and clearly see who paid what.' %}

{% trans 'The idea behind SplitTrip' %}

{% trans 'Group trips are fun, but tracking shared expenses can quickly become confusing.' %}

{% trans 'People pay for different things — food, transport, accommodation — and it becomes hard to remember who paid and how much everyone should contribute.' %}

{% trans 'SplitTrip was created to make that process simple and transparent.' %}

{% trans 'With SplitTrip you can:' %}

  • {% trans 'Create shared trip events' %}
  • {% trans 'Invite participants or join existing trips' %}
  • {% trans 'Record expenses during the trip' %}
  • {% trans 'See how much each person paid and how much they should share' %}

{% trans 'The goal is to keep everything clear in one place.' %}
